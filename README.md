Added a potentiometer to analog input A2. With this potentiometer, I can shift the output angle so, that with 0 rotation of the potentiometer, there is no angle added, and then by rotating the potentiometer knob it is possible to adjust up to 1,2,3,...90, 91, .. 180,181,... 270,271, ...358, 359, 360 degrees stepless

A picture of the arrangement.

There are 2 pushbutton, one is used for change to blinking and constant light.
